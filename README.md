# Multispecies Hackathon – COSS [Sunbird](https://sunbird.org/) | To know more...

**This repository hosts resources and workflows for the hackathon project integrating **Sunbird** Stacks (Reference Components).**

Core Challenge Tracks Participants will form teams to build practical prototypes focused on one of three main themes:
- Biodiversity (**Seeing, Understanding, Protecting**): Building tools to identify and monitor life, using applications like AI species classification, bioacoustic analysis, and environmental DNA tracking.
- Human-Animal Coexistence (**Sharing Space, Building Harmony**): Developing solutions to help humans and wildlife share space safely, such as early warning systems for conflict prevention, smart wildlife corridors, and urban ecology solutions.
- Conservation (**Protecting, Restoring, Regenerating**): Moving toward active regeneration by building anti-poaching technologies, climate adaptation strategies, and platforms that track restoration success
